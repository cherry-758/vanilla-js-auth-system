🔐 Vanilla JS Authentication System

A lightweight, fully functional Signup, Login, and Protected Dashboard system built with pure Vanilla JavaScript, HTML5, and CSS3.

Features
- User Signup:** Save user credentials in `localStorage`.
- User Login:** Authenticate existing users against stored credentials.
- Session Guard:** Protect `dashboard.html` from unauthorized direct access.
- Logout:** Clear active session and redirect back to login.
- Responsive UI:** Clean and simple layout.

Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Storage: Web Storage API (`localStorage`)
